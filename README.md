# DA工具箱

单文件 **`index.html`**（内含完税证明整理与资格审核、拼图工具等），浏览器本地运行，无需安装、不上传服务器。

本目录位于工作区 **`project/wanshui-tax-cert-master/`**。

---

## 使用

1. **不要用 `file://` 直接打开**（Chrome 对 pdf.js Worker 有限制）。请在上一级目录 `project/` 执行 `node local-http-server.cjs`，在浏览器访问：  
   `http://127.0.0.1:8765/wanshui-tax-cert-master/index.html`
2. 阅读免责声明后进入；在 **审核模式** 中选择 **单位 / 公司税单** 或 **个人所得税（上海）**。
3. **单位 / 公司税单**：可拖入多个 `.pdf` / `.zip`（详见页面说明）。**个人所得税（上海）**：每次仅 **1 个 PDF**（勿多文件、勿 ZIP 内含多份 PDF）；并须填写 **PDF 打开密码**。
4. 凑齐后点 **「开始整理」**。

---

## 审核模式与关键指标（KPI）

### 单位 / 公司税单

- **资格规则（摘要）**：以「一网通办」类口径为参考——全表最晚「税款所属期」结束月须在 **N-1 / N-2** 可接受范围内；并满足 **滚动 12 个月内每月至少有一条缴税（不分税种）**，或 **同一税种连续 4 个季度** 等按季特例。详见页面内「通过项 / 问题项」全文。
- **窗口内有效月份数（X/12）**：在「初步判断」区域 **大号高亮** 展示（以全表最晚所属期结束月为锚的 12 个自然月内有缴税的月份数，满分 12；细则见页面说明）。
- **文书式完整性**：对「证明编号 + 第 X 页/共 Y 页」等规则与上游一致；**不通过时终止整理**（逻辑未单独改动，以页面内实现为准）。

### 个人所得税（上海）

- **文件数量**：**仅接受 1 个 PDF**（解析后等价 PDF 数须为 1；多个上传文件或 ZIP 内多份 PDF 均会拒绝并提示）。
- **证明编号**：对 PDF **按页**解析证明编号；若识别到 **多个不同编号**（混装风险），**拒绝整理**并提示。
- **PDF 打开密码**：本模式 **必填**；单位模式不显示、不使用密码。
- **窗口内有效月份数（X/48）**：见页面「初步判断」高亮区（48 月窗口、≥36 有效月等规则以页面文案为准）。
- **文书式「第 X 页/共 Y 页」**：不对该形式做强校验；完整性卡片为说明性提示，**不因**此项阻断整理（与多页加密纳税记录常见形态一致）。

## 其他功能

- **隐私模式**（默认开启）：模糊显示纳税人名称、识别号、证明编号及文件名等。
- **不验电子签章**，结果仅供参考，以政务平台核验为准。

## 在线访问与站点密码（纯静态，无 Functions）

部署到 **Netlify / GitHub Pages / 任意静态托管** 时，可选为整站加一道 **浏览器内校验**（**不调用** Netlify Functions，**不产生** Functions credits）：

1. 用 **HTTPS 或 localhost** 打开同目录下的 **`set-da-password.html`**，输入两次站点密码，点「生成配置」，将 **`da-auth-config.js`** 下载或复制保存到与 **`index.html` 同一目录**。
2. 将该目录整包部署；**每次重新打开 / 刷新页面**都会要求输入密码（不在浏览器中长期保存登录状态）。
3. **关闭密码门**：不要部署 `da-auth-config.js`，或参考仓库里的 **`da-auth-config.sample.js`**，复制为 `da-auth-config.js` 并设 **`disabled: true`**（或留空 `saltB64` / `hashB64`）。
4. **`da-auth-config.js` 已列入 `.gitignore`**，请勿把含真实哈希的文件提交到公开仓库；发布时在本机生成后上传，或在 CI 用私密制品注入（勿打印到日志）。

**安全说明**：口令以 **PBKDF2-SHA256**（10 万次迭代）哈希形式写在 `da-auth-config.js` 中；拿到该文件仍可离线暴力破解弱口令，请使用 **足够长、随机的密码**。

## 文件

- `index.html` — 主程序
- `set-da-password.html` — 在浏览器中生成本地配置文件 `da-auth-config.js`
- `da-auth-config.sample.js` — 示例（关闭校验或作模板）
- `netlify.toml` — Netlify 仅静态发布（`publish = "."`）

## GitHub Pages（可选）

仓库开启 GitHub Pages 后，部署本目录；若需访问门，请同时上传 **`da-auth-config.js`**（由 `set-da-password.html` 生成）。`file://` 打开 `index.html` 时会自动跳过访问门，便于本地调试。
