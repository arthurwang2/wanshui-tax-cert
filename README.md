# 完税证明智能整理工具

单文件 HTML，浏览器本地运行，无需安装、不上传服务器。

## 使用

1. 用浏览器打开 `完税证明.html`
2. 拖入或选择多个 `.pdf` / `.zip`（可先凑齐再点「开始整理」）
3. 查看纳税人信息、税款明细表及已剔除项

## 功能

- 从电子版 PDF 提取：纳税人名称、识别号、税款所属时期、税种、实缴金额
- 按所属时期排序
- 自动剔除：同「所属时期 + 税种」下含**负数**、**滞纳金**或**罚没/罚款**类税种的全部记录
- 支持 ZIP 内多个 PDF 合并整理（最多 50 个）
- （勾选免责声明后）购车资格**初步判断**：滚动 12 个月内有缴税即可（不分税种）、最晚所属期 N-1/N-2、按季 4 季度特例；**不验电子签章**

## 说明

- 须为**可选中文字**的电子 PDF；纯扫描件无法解析
- 需联网加载 pdf.js、JSZip（首次打开）
