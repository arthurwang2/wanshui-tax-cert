# 完税证明智能整理工具

单文件 HTML，浏览器本地运行，无需安装、不上传服务器。

**在线使用：** https://arthurwang2.github.io/wanshui-tax-cert/

## 使用

1. 打开 `index.html` 或上述在线地址  
2. 免责声明：**进入（含资格判断）** / **跳过（仅整理）**  
3. 选择 **单位/公司税单** 或 **个人所得税（上海）**  
4. 上传 `.pdf` / `.zip`（最多 50 个 PDF），点「开始整理」

## 功能概览

| 能力 | 说明 |
|------|------|
| **双审核模式** | 单位购车社保规则 / 上海个税 48 月内 36 月 |
| **隐私模式**（默认开） | 脱敏名称、识别号、证明编号等 |
| **双通道解析** | 列坐标表解析 + 全表行补扫，减少漏行 |
| **金额交叉校验**（单位） | 表尾「金额合计」小写金额 vs 明细加总；界面「金额交叉校验」区块展示 |
| **完整性**（单位） | 证明编号、单页 PDF、页码齐全；解析条数/金额不符亦终止 |
| **按月合并展示** | 同一税款所属自然月首列合并 |
| **不验电子签章** | 辅助判断，以政务平台为准 |

## 单位模式 · 资格规则摘要

- 剔除：负数、滞纳金、罚没、所属期 &gt; 3 个月  
- **滚动 12 月**（不分税种）：所属期与自然月有日历交集即计有税（含单日所属期）  
- **连续 4 自然季度**：所属期须覆盖整季（Q2 = 4～6 月）  
- 按月路径：最晚所属期结束月 = N-1 或 N-2  

## 解析与材料要求

- **电子版 PDF**（文字可选中）；扫描件无法保证识别条数与合计  
- 自动过滤边栏「妥善保管」误并入税种（如「保印花税」→「印花税」）  
- 合计金额支持 `¥168898.72` 等无千分位格式  
- 首次打开需联网加载 pdf.js、JSZip
